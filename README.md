# Personal Projects

## Homemade Electrostatic Headphone System:
Electrostatic headphone systems operate by varying the voltage of two grids either side of a charged membrane. Due to the light weight nature of the membrane, this can deliver great sound quality but requires precise manufacturing to function correctly as well as high voltage amplification to create sufficient force to excite the membrane.
